概念

不只是翻牌游戏

「回忆杂货铺」是一份给朋友的生日礼物。四组卡牌对应四款一起玩过的游戏——光遇、原神、星露谷物语、胡闹厨房。每组回忆都藏在杂货铺的货架上，等着被翻开。

整个页面从纯白开始，随着游戏推进逐渐上色，通关后变成五彩蛋糕。颜色本身就是叙事的一部分。

叙事设计

货架上的故事

故事页用打字机效果逐字展开。每一段从一件货架上的物品开始，引出一段游戏回忆——但从不说破游戏名，只描写场景细节。每段配有对应的氛围装饰，随段落切换淡入淡出。

🕯️
一盏没点亮的蜡烛 高高的身影站成一排，有人跑在最前面忘了说话。 装饰：烛火呼吸光点
🎋
一截旧竹竿 隔了好久又回到水面上，竹筏晃晃悠悠的，谁也没急着靠岸。 装饰：水波细线飘过
💐
一小束干花 那一天，方块草地上开满花，谁都没有缺席。 装饰：花瓣飘落
🧾
一张沾着油污的收据 厨房里乱成一团，但盘子全端出去了。 装饰：收据纸影 + 油渍
游戏机制

不只是记忆力

16张卡牌分成四组游戏回忆。第一轮是标准的记忆配对，翻牌收集。第二轮加入捣蛋系统——卡牌会反抗、逃跑、偷偷换位。概率随剩余牌数递增。

🔄 抖动拒绝 翻开第二张时，卡牌有概率抖动然后翻回去，附带捣蛋消息
🦵 长腿逃跑 配对后卡牌长出像素小腿跑向别的格子，和另一张卡交换位置
🐛 慢慢爬行 卡牌偷偷离开原位，只走35%的距离，点击可以抓回来
📈 动态概率 剩余牌越少，捣蛋概率越高，从40%递增到100%

技术栈

用了什么

Vue 3 Vite Composition API CSS Variables CSS Animations ZPIX 像素字体

纯前端项目，没有后端。通关状态存储在 localStorage。所有动效使用 CSS animation + Vue Transition，没有引入动画库。组件结构拆分为 StartPage、StoryPage、GameBoard、BirthdayEnding 四个主页面 + TutorialPage、AlbumModal、AchievementModal 三个子组件。
